# Hospital  Analysis Dashboard (Excel Project)

## &#x20;

## Project Overview

## 

This project focuses on analyzing hospital patient data to identify patterns in readmissions, length of stay, and treatment effectiveness. The goal is to derive insights that help improve patient care and reduce unnecessary hospital readmissions.



&#x20;**Objectives**

Analyze patient demographics and hospital visits

Identify factors affecting readmission rates

Evaluate length of stay across different conditions

Provide actionable insights for hospital management

🛠️ Tools \& Technologies Used

Microsoft Excel

Pivot Tables

Charts \& Graphs

Slicers

KPI Metrics

Data Cleaning



&#x20;**Key Features of Dashboar**d

Interactive dashboard with slicers

KPI indicators:

Total Patients

Readmission Rate

Average Length of Stay

Visual analysis:

Readmission by Age Group

Specialty-wise Length of Stay

Medication Change Impact

Gender \& Race Distribution



&#x20;**Key Insights**

Elderly patients show higher readmission rates

Certain medical specialties have longer hospital stays

Medication changes may impact readmission probability

Demographic factors influence patient outcomes



&#x20;**Recommendations**

Focus on high-risk patient groups (elderly)

Improve post-discharge monitoring

Optimize treatment strategies for high readmission specialties

Enhance medication tracking systems



&#x20;**Challenges Faced**

Cleaning and structuring raw data

Creating meaningful KPIs

Designing an interactive dashboard

Connecting slicers across multiple pivot tables



&#x20;**Conclusion**



This project demonstrates how Excel can be used effectively for healthcare data analysis. The dashboard provides valuable insights that can help hospitals improve patient care and reduce readmissions.
